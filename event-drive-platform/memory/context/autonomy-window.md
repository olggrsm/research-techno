# T_aut — окно автономности

Расчётная граница автономной работы: N0 — 3 с, N1 — 5 мин, N2 — 15 мин, N3 — 1 ч. Для [[concept-k-event|K]] граница задаётся [[validity-window|48 ч]] и ёмкостью [[k-reserve|резерва]].
