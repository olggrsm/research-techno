# Напряжение 6: Ёмкость и длительность изоляции

Очередь конечна. Для E при изоляции дольше T_aut потеря допустима по заданной политике. Для K потеря запрещена, а отказ приёма запрещён в пределах 96 ч изоляции (решение заказчика), поэтому надёжность обеспечивается только ёмкостью: резерв под K считается по устойчивой скорости K × 48 ч (скользящее окно, истёкшая K удаляется сразу) × коэффициент репликации. Физически бесконечной очереди не бывает. Если скорость K превысит расчётную, возможны лишь отказ приёма, вытеснение или остановка узла. Заказчик принял остаточный риск: отказ приёма K допускается только после 96 ч простоя.
