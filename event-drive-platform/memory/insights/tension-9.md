# Напряжение 9: Команды K на обеих сторонах разделения

Если команды на один объект принимаются по обе стороны разрыва, после реконвергенции состояния расходятся, а для K конфликт-разрешение «последний выиграл» теряет команды молча. Поэтому выбран single-writer: цена — недоступность модификации объекта, пока недоступен его владелец (при этом команда не теряется, а ждёт).
