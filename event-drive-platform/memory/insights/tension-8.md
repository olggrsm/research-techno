# Напряжение 8: Команды K и актуальность

Команда, пролежавшая в очереди изолированного узла, может устареть: запуск процесса или изменение данных по устаревшему решению опаснее потери. Поэтому «не терять» трактуется как «исход всегда зафиксирован» (исполнена, отклонена, просрочена), а не «исполнить любой ценой». Срок актуальности задаёт заказчик по типам команд.
