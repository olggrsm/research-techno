## R — Живучесть и работа при сетевых ограничениях

**Требование.** Для каждого объекта модели ДОЛЖЕН быть определён единственный узел-владелец (single-writer); команды K над объектом маршрутизируются владельцу, при его недоступности ставятся в durable-очередь и не применяются на других узлах.

**Критерий.** Тест разделения: две стороны выдают команды на один объект, расхождения состояния после реконвергенции 0, порядок применения по объекту сохранён.

**Приоритет.** MUST
