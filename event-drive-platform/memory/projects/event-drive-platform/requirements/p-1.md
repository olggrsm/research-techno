## P — Быстродействие

**Требование.** Для цепочки producer → broker → consumer → обработка ДОЛЖЕН существовать опубликованный latency budget с разбивкой по компонентам.

**Критерий.** Сумма бюджетов компонентов ≤ SLO цепочки; бюджет пересматривается при смене компонента.

**Приоритет.** MUST
