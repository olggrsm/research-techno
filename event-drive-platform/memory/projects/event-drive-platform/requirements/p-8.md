## P — Быстродействие

**Требование.** Доставка по умолчанию — at-least-once; потребители ДОЛЖНЫ быть идемпотентны (дедупликация по event ID); связь БД и событий — через transactional outbox/inbox.

**Критерий.** Fault-injection (падение процесса между записью и публикацией, 10 000 повторов): 0 потерянных, 0 повторных побочных эффектов.

**Приоритет.** MUST
