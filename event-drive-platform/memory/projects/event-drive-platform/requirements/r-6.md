## R — Живучесть и работа при сетевых ограничениях

**Требование.** Для каждого класса событий ДОЛЖНЫ быть заданы TTL, приоритет и политика вытеснения при переполнении.

**Критерий.** При переполнении буфера вытесняются только события категории E, начиная с низшего приоритета; потери фиксируются в метрике. События K не вытесняются никогда (см. R-14).

**Приоритет.** MUST
