## R — Живучесть и работа при сетевых ограничениях

**Требование.** Для E время реконвергенции после восстановления связи ДОЛЖНО быть не больше T_aut данного класса [П]. Для K накопленное отставание не превышает 48 ч (более старые K истекают и удаляются, R-18); догонка идёт с приоритетом K, срок актуальности (R-18) идёт и во время догонки.

**Критерий.** Накопленное отставание = пиковая скорость × T_aut; догонка завершается за ≤ T_aut при продолжающемся потоке. Это требует пропускной способности репликации не менее 2× пиковой скорости [П]: время догонки = B/(C−r) ≤ T при C ≥ 2r. Для K: отставание B = r×I при изоляции I; время догонки = I×r/(C−r). При I = 48 ч: C = 2r даёт 48 ч, C = 10r даёт около 5,3 ч, C = 49r даёт 1 ч; при изоляции дольше 48 ч отставание не растёт. Допустимое время догонки K задано заказчиком: не более 2 ч после восстановления связи. Из формулы при I = 48 ч (наихудший случай) и времени догонки 2 ч: 48r/(C−r) ≤ 2 ч, откуда C ≥ 25r, где r — исходящий поток репликации узла. Для потока r из таблицы раздела 2 (N1 20 МБ/с, N2 2,2 ГБ/с, N3 4 ГБ/с) это около 0,5 ГБ/с (4 Гбит/с), 55 ГБ/с (440 Гбит/с) и 100 ГБ/с (800 Гбит/с) на узел. Для изоляции длительностью I ≤ 1 ч требуется только C ≥ 1,5r. Критерий: тест изоляции на 48 ч при устойчивой скорости K завершается догонкой за ≤ 2 ч.

**Приоритет.** MUST
