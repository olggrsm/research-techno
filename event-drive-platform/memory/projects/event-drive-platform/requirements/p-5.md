## P — Быстродействие

**Требование.** Любые опубликованные числа производительности ДОЛЖНЫ сопровождаться режимом durability (fsync-per-ack, acks=all, кворум).

**Критерий.** Бенчмарк без режима durability не принимается в сравнение.

**Приоритет.** MUST
