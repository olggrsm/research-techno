# ADR-006: Single-writer для команд K

**Статус:** предложено

## Решение

У каждого объекта модели один узел-владелец; команды маршрутизируются владельцу, при его недоступности ждут в durable-очереди и не применяются на других узлах.

## Альтернативы

- Последний выиграл (LWW): молча теряет команды K
- CRDT: сходимость без гарантии исполнения команд

## Последствия

- Модификация объекта недоступна, пока недоступен владелец
- Команда ждёт до valid-until 48 ч, затем статус «просрочена»
