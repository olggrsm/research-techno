# ADR-003: Ячеистая (cell-based) изоляция отказов

**Статус:** предложено

## Решение

Платформа делится на ячейки без общего состояния; маршрутизатор между ячейками stateless и продублирован; выкат волнами через canary-ячейки; размер ячейки подбирается по blast radius (стартово 1/20).

## Альтернативы

- Единый кластер с multi-AZ: защищает от отказа зоны, но не от плохого релиза и poison pill
- Мелкие ячейки (1/100): меньший радиус, выше операционная нагрузка

## Последствия

- Зависимость между ячейками недопустима, миграции — основной источник такой зависимости
- Нужна автоматизация развёртывания
