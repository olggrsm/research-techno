# ADR-005: At-least-once плюс идемпотентность, transactional outbox

**Статус:** предложено

## Решение

Доставка по умолчанию at-least-once; потребители K дедуплицируют по ключу команды; связь БД и событий через outbox/inbox. Exactly-once эффект достигается идемпотентным исполнением.

## Альтернативы

- Exactly-once внутри брокера: не покрывает БД и внешние системы

## Последствия

- Дубли неизбежны (в том числе MirrorMaker 2 и мост), идемпотентность обязательна у всех потребителей
