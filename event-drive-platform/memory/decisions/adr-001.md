# ADR-001: Гибридная двухслойная архитектура: Kafka в ядре, NATS на краю

**Статус:** предложено

## Решение

Ядро и регионы (N2–N3) строятся на Kafka 4.x; край (N0–N1) на NATS JetStream с leaf nodes; между слоями мост NATS→Kafka с CloudEvents и идемпотентным ключом.

## Альтернативы

- NATS-центричный вариант A: слабее экосистема аналитики и долгого хранения
- Kafka везде: тяжёл для N0/N1, нет outbound-only leaf из коробки
- Pulsar: сложнее в эксплуатации, мульти-аренда не нужна
- Redpanda везде: BSL 1.1 и противоречивые бенчмарки

## Последствия

- Две технологии требуют единого контракта событий X-1…X-3
- Нужен мост и дедупликация по event ID
