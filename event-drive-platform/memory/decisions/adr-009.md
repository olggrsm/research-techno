# ADR-009: Девять напряжений требований: указатель на docs/adr/0008

**Статус:** предложено

## Решение

Напряжения требований перенесены в `docs/adr/0008-requirement-tensions.md`. Эта запись — указатель: она не вводит нового решения, а связывает перенесённые напряжения с заметками `tension-1…9` и с записями `adr-001…adr-008`, которые их снимают.

## Соответствие напряжений и решений

| Напряжение | Снимается |
|---|---|
| [[tension-1]] Долговечность и задержка | [[adr-002]] |
| [[tension-2]] Автономность и безопасность | [[adr-005]] |
| [[tension-3]] Автономность и согласованность | не снимается — объявление модели согласованности по R-11 |
| [[tension-4]] Порядок и масштаб | [[adr-001]], доменный ADR-0003 |
| [[tension-5]] Exactly-once и границы системы | [[adr-001]], доменный ADR-0001 |
| [[tension-6]] Ёмкость и длительность изоляции | [[adr-007]] |
| [[tension-7]] P2P-обмен и долговечный журнал | [[adr-008]] |
| [[tension-8]] Команды K и актуальность | [[adr-001]] |
| [[tension-9]] Команды K на обеих сторонах разделения | [[adr-001]], [[adr-006]] |

## Последствия

- Напряжения проверяются при добавлении решения в каталог, а не открываются заново.
- Напряжение 3 остаётся открытым по своей природе: его закрывает объявление модели согласованности для каждого класса данных.
