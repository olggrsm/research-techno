# ADR-004: Причинный порядок на гибридных логических часах

**Статус:** предложено

## Решение

Каждое событие несёт HLC-метку и идентификатор источника; обещается причинный порядок, глобальный total order не обещается.

## Альтернативы

- Векторные часы: размер растёт с числом узлов, не нужны для обещанных гарантий
- Только физическое время: расхождение часов ломает причинность

## Последствия

- HLC не доказывает конкурентность событий
- Для корректного replay логов возможен Replay Clock
