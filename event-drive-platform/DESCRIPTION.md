Цель: сформировать методологию, на основе кайзен подхода, для разработки программных продуктов в парадигме эволюционной архитектуры в ИТ.

Состав ключевых документов методологии:
1. Видение - документ описывает основные проблемы в разработке программного обеспечения текущего периода 2026. Критику современных подходов к разработке и управления изменениями в требованиях к продукту в рамках его жизненного цикла. Документ должен быть построен по формату аналитической записки не более 10 страниц.
   Должны иметь разделы: 
		-  ключевые проблемы
		-  тенденции и перспективные подходы по устранению выявленных проблем
		-  компании и команды , которые пытаются реализовывать наиболее эффективных методы в разработке ПО.
		- сделать выводы с учетом сравнительного анализа выявленных современных подходом в разработке и подхода кайзен. 
2. Описание методологии
            - что и кто является объектом управления
            - кто является субъектом
            - описать ключевые роли процесса управления качеством на основе подхода кайзен
            - описать этапы процесса управления качеством  и области ответственности  участников процесса
            - какие ресурсы необходимы для реализации подхода
            - какие действия необходимы в первую очередь, чтобы начать внедрение методологии для разработки и управления качеством продукта ПО.
            -  сделать схему  описывающую ключевые этапы процесса кайзен с нанесенными зонами ответственности ключевых ролей.
            - сделать схему  описывающую временную зависимость качества продуктов от времени внедрения метода кайзен
            - сформировать график внедрения, согласно плана  внедрения
3. План внедрения
        - описание оптимальных этапов внедрения с целевыми показателями качества реализации этапа, ключевые роли для каждого этапа.
        - описать требования к ключевым ресурсам (временные, человеческие, финансовые) 
        - предложить наиболее оптимальные требования к организационной структуре на каждом этапе внедрения
