Прямая связь с кайдзен: fitness function — это, по сути, автоматизированный
аналог цикла PDCA/SDCA ([[memory/facts/pdca/definition]],
[[memory/facts/sdca/definition]]) на уровне архитектуры: Standardize
(зафиксировать характеристику как fitness function) → Do (изменение) →
Check (автоматическая проверка в конвейере) → Act (корректировка при
нарушении). Это прямой ответ на проблему архитектурной эрозии из Этапа 1
([[memory/insights/technical-debt-2026]]) — вместо периодических крупных
"проектов модернизации" эволюционная архитектура встраивает непрерывную,
малую, автоматизированную проверку прямо в процесс разработки — принцип,
максимально близкий к духу кайдзен.
