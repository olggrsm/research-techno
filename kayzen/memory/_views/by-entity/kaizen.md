# Facts — kaizen

- **definition**: Continuous improvement ("непрерывное совершенствование") across work, business, and personal life; popularized worldwide by Masaaki Imai's 1986 book "Kaizen: The Key to Japan's Competitive Success". (unknown → present) — `memory/facts/kaizen/definition.md`
- **popularized-by**: masaaki-imai (note: Imai described and popularized the philosophy via his 1986 book; he did not invent it — kaizen practices predate the book, e.g. Kaoru Ishikawa's QC circles from 1949). (unknown → present) — `memory/facts/kaizen/popularized-by.md`
- **practiced-by**: toyota, which implements kaizen through small, regular changes at all levels of the organization. (unknown → present) — `memory/facts/kaizen/practiced-by.md`
- **related-concept**: lean-production — Lean Production was developed by Toyota and incorporates kaizen as one of its core principles. (unknown → present) — `memory/facts/kaizen/related-concept.md`
